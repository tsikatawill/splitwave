Each app, its own speaker.

Splitwave lives in your Mac's menu bar and sends each app's sound wherever you want it. Music on your AirPods, the movie on the TV, the call on your speakers, all at the same time.

    Set it up once
    
          
    Link the tool so splitwave works anywhere (macOS asks for your password):
    
          
    sudo mkdir -p /usr/local/bin
sudo ln -sf /Applications/Splitwave.app/Contents/MacOS/splitwave /usr/local/bin/splitwave
    
          
    Or skip Terminal
    
          
    Anything that can open a link can switch your setups: splitwave://setup/Desk from Shortcuts, Raycast or a hotkey.

    Questions
    
      
    
        
    
          Does Splitwave record anything?
          
    No. macOS calls the permission “system audio recording” because the same feature powers recorders, but Splitwave only passes sound from an app straight to your speakers. It has no network access, no accounts and no analytics.
    
        
    
        
    
          Can I send two browser tabs to different speakers?
          
    Not yet. Browsers play every tab through a single process, so macOS sees the whole browser as one app. To split two sites, play them in two browsers, or save one as a Safari web app with File › Add to Dock.
    
        
    
        
    
          Why does one app sound out of sync on two outputs?
          
    Bluetooth headphones and speakers run about 100–200 ms behind wired ones. That's fine for music in different rooms, less so in the same room.
    
        
    
        
    
          Does it need a driver or system extension?
          
    No. Splitwave uses the audio taps built into macOS 14.2 and later. To uninstall, quit it and delete it from Applications.
    
        
    
        
    
          Why does macOS say it can't check the app?
          
    Splitwave is free and isn't signed through Apple's paid developer program yet, so macOS asks you to confirm it once in System Settings › Privacy & Security. The source is on GitHub if you'd rather build it yourself.
